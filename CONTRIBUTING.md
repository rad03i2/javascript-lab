# Contributing

Thanks for improving JavaScript Lab. Keep changes focused and dependency-light.

1. Create a branch and make one coherent change.
2. Run `npm test` and `npm run check`.
3. Add tests for behavior changes and update both README language sections when user-facing behavior changes.
4. Never commit credentials, personal data, generated dependency folders, or copied code without a compatible license.
5. Open a pull request describing what changed and how it was validated.

By contributing, you agree that your contribution may be distributed under the MIT License.
